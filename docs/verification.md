# Проверка MVP

Дата: 18.10.2026. Это проверка реализации инструмента, а не приёмка преобразованного клиентского проекта.

## Наблюдаемые результаты

- Независимый запуск `.venv/bin/python -m pytest -q`: **120 passed, 1 skipped, 1 warning** за 10.65 с. Проверены неизменившиеся до и после запуска runtime, tests и конфигурация. SHA-256 списка из 34 проверяемых файлов: `4c95fdb173788ba27361e2e674a7e712d18abbf517fd4628f488d73354de178b`.
- Пропущен `tests/test_postgres.py`: локально не задан `V2C_TEST_POSTGRES_URL`. В GitHub Actions этот тест запускается с выделенным PostgreSQL 16 и миграциями Alembic.
- Локально выполнены Alembic upgrade на временной SQLite, HTTP smoke настоящего Uvicorn (готовность, авторизация, проект, импорт архива, постановка запуска и выдача панели), Python compileall и проверка синтаксиса JavaScript через Node.
- Импорт и поставка проверены с настоящими временными Git-репозиториями/bundles и запуском переносимого скрипта из распакованной поставки. Внешние HTTP, VM и Docker в основном наборе представлены управляемыми тестовыми портами.

## Что ещё требует подключённой среды

Реальная модель, S3, облачный шлюз создания и удаления VM, runner с Docker/PostgreSQL и mTLS не проходили сквозного испытания в этой среде. Контейнерная сборка и PostgreSQL дополнительно проверяются CI; результат конкретного запуска следует читать в GitHub Actions. Визуальный браузерный проход панели не выполнен: браузер недоступен; проверены HTTP-ресурсы и синтаксис.

Преобразование LeraBack и другого незнакомого проекта, независимая доработка новым ИИ, приёмка отдельным разработчиком и стоимость настоящего запуска остаются этапами PoC. Наличие зелёных тестов инструмента не даёт проекту статус READY.

Для этого этапа нужны доступ к VM управления, настроенные S3 и модельный профиль, закреплённый образ проекта и реализующий [протокол VM lifecycle](runner-protocol.md) инфраструктурный шлюз. Параметры запуска описаны в [deployment.md](deployment.md).
